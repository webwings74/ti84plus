# ti84plus
Programming and calculating on the Texas Instruments Ti84 Plus CE-T Python Edition

## Programma's

| Bestand | Omschrijving |
|---|---|
| `ti84-hello.py` | Hello world / basis input-output voorbeeld. |
| `ti84-math.py` | Demonstratie van de standaard en extended (`math`) functies. |
| `varfmt.py` | Voorbeeld van een variabele kolombreedte in `str.format()`. |
| `bmi.py` | Berekent de Body Mass Index (BMI) uit massa en lengte. |
| `inhoud-cylinder.py` | Berekent de inhoud van een cilinder uit straal en hoogte. |
| `afstand.py` | Grootcirkelafstand tussen twee vaste coördinaten (haversine-formule). |
| `gc-dist.py` | Grootcirkelafstand tussen twee door de gebruiker ingevoerde coördinaten. |
| `getgdist.py` | Grootcirkelafstand berekend uit een JSON-payload met coördinaten. |
| `gc-crs.py` | Grootcirkel begin- en eindkoers tussen twee coördinaten. |
| `dhc2.py` | Weight & Balance programma voor een DeHavilland DHC-2 Beaver op drijvers (brandstof, cabin load, W&B-berekening met CG-check). |
